# 01. 概念阶段（CDCP）

> 把机会点转化为可立项的产品概念，回答“值不值得做、大致做什么”，通过 CDCP 获得计划阶段授权。

## 0. 一图看懂

```mermaid
flowchart LR
    A["机会点"] --> B["概念/需求/商业论证"]
    B --> C{"Pre-TR1"}
    C -->|通过| D{"CDCP"}
    D -->|Go| E["进入计划"]
    D -->|Rework| B
    D -->|No-Go| F["关闭/观察"]
```

## 1. 阶段门禁

- **门禁**：CDCP（商业决策）+ Pre-TR1（概念技术预审）
- **准入**：机会点初筛完成、战略/路标匹配、PDT 经理候选人指定、初步客户/市场证据、合规初筛无红线。
- **准出**：商业价值成立、目标客户/场景清晰、技术可行、风险可控、资源可承诺、合规无红线、立项申请书获批。

## 2. 重点抓什么

**本阶段重点**：商业论证与市场证据、初始需求与概念方案、技术可行性、初始风险/合规/IP/成本、PDT 组建与授权

| 必须抓住 | 容易漏掉 | 失败信号 |
|---|---|---|
| ✅ 商业价值成立<br>✅ 目标客户/场景清晰<br>✅ 技术可行<br>✅ 风险可控<br>✅ 资源可承诺 | ⚠️ 只有市场故事，没有客户证据<br>⚠️ 成本/风险漏项<br>⚠️ 合规/IP 红线未识别 | 🚨 CDCP 反复 Rework<br>🚨 关键假设没有验证计划<br>🚨 PDT 核心成员不到位 |
