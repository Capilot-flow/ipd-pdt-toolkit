# 03. 开发阶段（TR1~TR4）

> 按基线完成系统/详细设计、开发、集成，通过 TR1~TR4 逐级确认技术成熟度，形成可验证版本/样机。

## 0. 一图看懂

```mermaid
flowchart LR
    A["TR1 需求/方案"] --> B["TR2 系统/接口"]
    B --> C["TR3 详细设计"]
    C --> D["TR4 开发/集成"]
    D --> E{"VRR 验证准入"}
    E -->|Go| F["进入验证"]
    E -->|Rework| D
```

## 1. 阶段门禁

- **门禁**：TR1~TR4（技术评审）+ VRR（验证准入，管理决策）
- **准入**：PDCP Go、需求/架构基线冻结、开发环境/工具链就绪、开发资源到位、变更/配置管理生效。
- **准出**：设计完成、集成通过、阻断缺陷清零、版本/文档受控、验证资源就绪。

## 2. 重点抓什么

**本阶段重点**：系统/详细设计、接口与集成、DFMEA/DFM/DFT/DFS、单元/集成测试、样机/BOM/工艺、设计变更与缺陷闭环

| 必须抓住 | 容易漏掉 | 失败信号 |
|---|---|---|
| ✅ 需求可追溯<br>✅ 接口闭合<br>✅ 设计可制造/可测试<br>✅ 阻断缺陷清零<br>✅ 版本受控 | ⚠️ 接口只写“待定”<br>⚠️ DFM/DFT/DFS 后置<br>⚠️ 变更不走 CCB | 🚨 TR 开成汇报会<br>🚨 缺陷越修越多<br>🚨 样机问题重复出现 |
