# 04. 验证阶段（TR5）

> 验证产品满足需求、质量、可靠性、安全、合规要求，缺陷收敛到发布门槛，通过 TR5 进入发布准备。

## 0. 一图看懂

```mermaid
flowchart LR
    A["TR5 验证"] --> B{"缺陷收敛"}
    B -->|是| C{"LRR 发布准入"}
    B -->|否| D["回炉修复"]
    C -->|Go| E["进入发布"]
    C -->|Rework| D
```

## 1. 阶段门禁

- **门禁**：TR5（技术评审）+ LRR（发布准入预审）
- **准入**：TR4 通过、候选版本/样机冻结、测试环境/数据就绪、认证/试产条件就绪、缺陷门槛定义。
- **准出**：测试覆盖达标、阻断/严重缺陷清零、性能/可靠性/安全/合规通过、试产良率达标、服务/文档/培训就绪、剩余风险接受。

## 2. 重点抓什么

**本阶段重点**：系统/性能/可靠性/安全测试、UAT/Beta/试点、认证/安规/EMC、试产/小批量、缺陷收敛与质量度量、服务/文档验证

| 必须抓住 | 容易漏掉 | 失败信号 |
|---|---|---|
| ✅ 测试覆盖达标<br>✅ 阻断/严重缺陷清零<br>✅ 认证/合规通过<br>✅ 试产良率达标<br>✅ 服务/文档就绪 | ⚠️ 只测正常路径<br>⚠️ 认证样品/周期没预留<br>⚠️ 遗留缺陷没有接受人 | 🚨 TR5 前还在改需求<br>🚨 缺陷关闭率突然“变好”<br>🚨 试产问题没有根因 |
