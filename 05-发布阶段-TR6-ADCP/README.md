# 05. 发布阶段（TR6/ADCP）

> 完成上市/量产/交付/服务准备，通过 TR6 和 ADCP 获得上市授权，建立发布后监控与回退机制。

## 0. 一图看懂

```mermaid
flowchart LR
    A["TR6 发布/量产"] --> B{"ADCP"}
    B -->|Go| C["上市/交付"]
    B -->|Rework| D["整改/分阶段"]
    B -->|No-Go| E["延迟/取消"]
    C --> F["发布后监控"]
```

## 1. 阶段门禁

- **门禁**：TR6（技术评审）+ ADCP（商业决策）
- **准入**：TR5 通过、发布包/版本冻结、量产/交付就绪、市场/销售/定价就绪、服务/培训就绪、认证完成、回退方案批准。
- **准出**：发布门禁全过、首单/首台可交付、支持团队就绪、监控/回退就绪、剩余风险接受。

## 2. 重点抓什么

**本阶段重点**：发布计划/市场/定价、量产/供应/交付、服务/培训/文档、回退方案、ADCP 决策、发布后监控

| 必须抓住 | 容易漏掉 | 失败信号 |
|---|---|---|
| ✅ 发布门禁全过<br>✅ 首单/首台可交付<br>✅ 供应/服务就绪<br>✅ 回退方案可执行<br>✅ 剩余风险接受 | ⚠️ 只盯质量，漏供应/服务<br>⚠️ 回退方案没演练<br>⚠️ 渠道/培训未就绪 | 🚨 ADCP 前还在补认证<br>🚨 首单交付靠“特事特办”<br>🚨 发布后问题无人接 |
