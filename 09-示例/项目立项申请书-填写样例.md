## 1. 项目背景与机会

**背景**：国内中小型电商仓配中心仍大量依赖人工拣选，平均拣选错误率 1.2%~2.5%，旺季临时用工成本上涨 30% 以上。现有 AGV 方案投入高、部署周期长，中小仓难以承受。

**机会**：轻量化、可快速部署的“拣选终端 + 云端调度”方案，单仓投入控制在 20 万元以内，部署周期 ≤ 7 天。目标市场为日单量 3,000~20,000 单的区域仓配中心。

**为什么是现在**：① 视觉识别模组成本较 2023 年下降约 35%；② 客户对“柔性自动化”接受度提升；③ 公司现有 WMS 客户中有 60+ 家存在拣选痛点，具备交叉销售基础。

## 3. 产品概念与范围

**产品概念**：一套“终端 + 边缘网关 + 云调度”的轻量化拣选系统。终端集成扫码、称重、拍照复核、语音提示；边缘网关负责本地调度；云端提供波次优化、绩效看板和远程运维。

**核心范围（V1.0）**：

- 拣选终端硬件（含支架、电源、扫码/称重/拍照模组）；
- 边缘调度软件（本地部署，支持 50 台终端）；
- 云端管理平台（多仓、绩效、告警、OTA）；
- 标准 API（对接主流 WMS）；
- 实施工具包与培训。

**不做清单（V1.0 明确不做）**：

- 不做 AGV/AMR 搬运；
- 不做自动打包机；
- 不做冷链/危险品版本；
- 不做自研 WMS；
- 不做海外多语言版本（V1.1 再评估）。

## 4. 业务价值与商业目标

| 指标 | 目标（上市后 12 个月） | 说明 |
|---|---|---|
| 签约客户 | ≥ 30 家 | 以现有 WMS 客户交叉销售为主 |
| 终端出货 | ≥ 1,200 台 | 单仓平均 40 台 |
| 年度收入 | ≥ 2,400 万元 | 硬件 + 软件订阅 + 实施服务 |
| 毛利率 | ≥ 42% | 硬件 30%、软件 65%、服务 45% |
| 客户拣选错误率 | 降至 ≤ 0.3% | 对比客户现状 |
| 部署周期 | ≤ 7 天/仓 | 标准场景 |
| 战略价值 | 形成“硬件+软件+服务”的第二增长曲线 | 降低对 WMS 项目制的依赖 |

**投资回收**：项目总投入 1,850 万元，预计 26 个月收回投资；敏感性分析显示，若售价下降 10%，回收期延长至 34 个月，仍在公司阈值内。

## 8. 成功/验收标准

**项目成功标准**：

1. 按计划通过 CDCP/PDCP/TR1~TR6/ADCP；
2. 上市后 12 个月签约 ≥ 30 家、出货 ≥ 1,200 台、收入 ≥ 2,400 万元；
3. 客户拣选错误率 ≤ 0.3%，部署周期 ≤ 7 天；
4. 毛利率 ≥ 42%，投资回收 ≤ 30 个月；
5. 发布前严重缺陷为 0，客户满意度 ≥ 4.2/5。

**验收方式**：DCP/TR 评审 + 试点仓数据 + 财务核算 + 客户调研。

## 10. 终止/退出条件

出现以下任一情况，建议 CDCP/PDCP 重新评估或终止：

1. POC 阶段视觉识别率无法达到 99.5%，且备选方案成本超目标 20%；
2. 目标客户付费意愿调研中，≥ 60% 客户认为价格高于价值；
3. 关键模组供应中断且无替代；
4. 认证出现无法整改的红线项；
5. 上市后 12 个月未达到签约 15 家/出货 500 台，且无明确改进路径。
