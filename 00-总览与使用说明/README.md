## 每个阶段文件夹里有什么

```text
01-概念阶段-CDCP/
├── README.md          # 本阶段目标、门禁、物料清单
├── 模板/              # 要填的文档
├── 台账/              # 动态登记表
├── 检查表/            # DCP/TR 自检清单
└── SOP/               # 本阶段流程
```

> 文件命名统一为 `编号-中文名称.md`，例如 `CP-T-01-项目立项申请书.md`。编号中的 `T/R/C/S` 分别代表模板/台账/Checklist/SOP。
