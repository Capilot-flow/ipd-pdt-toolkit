# 06. 生命周期与退市（LDCP/EOL）

> 监控产品绩效、质量、成本和客户满意度，持续优化，评估并执行退市，完成客户迁移、服务终止和知识沉淀。

## 0. 一图看懂

```mermaid
flowchart LR
    A["绩效/质量/客户监控"] --> B{"继续经营"}
    B -->|是| C["迭代/降本"]
    B -->|否| D{"EOL 评估"}
    D -->|Go| E["退市执行"]
    D -->|Rework| F["补迁移/库存方案"]
    D -->|No-Go| C
```

## 1. 阶段门禁

- **门禁**：PRR（上市后复盘）+ LDCP/EOL DCP（退市决策）
- **准入**：ADCP Go/产品上市、绩效指标/责任人/预算明确、退市触发条件定义、服务/合同/库存台账建立。
- **准出**：绩效达标或退市条件成立、客户迁移可行、库存/服务/合同风险可控、财务影响可接受。

## 2. 重点抓什么

**本阶段重点**：绩效/满意度/质量监控、版本迭代/降本、EOL 评估、客户迁移、库存/服务终止、复盘与归档

| 必须抓住 | 容易漏掉 | 失败信号 |
|---|---|---|
| ✅ 绩效/质量达标<br>✅ 退市条件成立<br>✅ 客户迁移可行<br>✅ 库存/服务风险可控<br>✅ 财务影响可接受 | ⚠️ 只算库存，不算客户流失<br>⚠️ 服务合同未到期<br>⚠️ 数据/知识未归档 | 🚨 绩效持续下滑<br>🚨 客户投诉集中<br>🚨 备件/服务成本失控 |
